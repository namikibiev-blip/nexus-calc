ПРОФЕССИОНАЛЬНЫЙ КАЛЬКУЛЯТОР
ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ИСПОЛЬЗОВАНИЮ
====================================
ЗАПУСК НА WINDOWS
====================================
Откройте папку с файлами калькулятора.
Найдите файл index.html.
Дважды щёлкните по нему мышью.
Калькулятор откроется в браузере.
Проверьте работу основных математических операций.
Примечание: для установки калькулятора как приложения и полноценной работы без интернета может потребоваться локальный сервер или HTTPS-сайт.
====================================

2. УСТАНОВКА НА ANDROID
Разместите файлы приложения на HTTPS-сайте.
Откройте адрес сайта в браузере Android.
Дождитесь полной загрузки приложения.
Откройте меню браузера.
Выберите «Установить приложение» или «Добавить на главный экран», если доступно.
====================================

3. РАБОТА БЕЗ ИНТЕРНЕТА
При первом запуске подключитесь к интернету.
Откройте приложение и дождитесь загрузки файлов.
Убедитесь, что сервис-воркер sw.js подключён правильно.
Отключите интернет и проверьте работу калькулятора.
Работа без интернета возможна после правильной настройки и кэширования необходимых файлов.
====================================

4. ФАЙЛЫ ПРИЛОЖЕНИЯ
index.html — главная страница калькулятора.
manifest.json — настройки установки приложения.
sw.js — поддержка офлайн-режима.
icon-192.png — иконка размером 192 × 192 пикселя.
icon-512.png — иконка размером 512 × 512 пикселей.
README.txt — инструкция пользователя.
Все файлы должны иметь правильные имена и находиться в соответствующих папках проекта.
====================================

5. ПРОВЕРКА РАБОТЫ
Перед использованием проверьте:
сложение и вычитание;
умножение и деление;
проценты и другие доступные функции;
правильность отображения на экране;
работу без подключения к интернету.
====================================
